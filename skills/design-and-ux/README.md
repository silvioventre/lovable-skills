# design-and-ux

Skill di design e UX: direzione artistica, sistemi visivi, tipografia, layout, motion, accessibilità — il lavoro sull'interfaccia, non sui contenuti o sul codice in generale.

| Skill | Cosa fa |
|---|---|
| [art-direction](art-direction/) | 21 comandi di design per Lovable: costruire una direzione visiva, criticare, rifinire, rendere più audace o più sobria un'interfaccia. Derivata da [Impeccable](https://github.com/pbakaus/impeccable) (Apache-2.0). |

Aggiungi qui le skill nel formato `skills/design-and-ux/<nome-skill>/SKILL.md` (vedi `skills/_template/SKILL.md`).
